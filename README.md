# EASTOKYO

EASTOKYO is an independent art magazine based in Tokyo, looking outward.

The site is built with Next.js and deployed at `https://www.eastokyo.com`.

## Development

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Checks

```bash
pnpm check
```

This runs linting, TypeScript checks, and a production build.

## Editorial structure

The homepage presents the current issue and links into permanent magazine sections and story pages as they are built. EASTOKYO is the sole publication identity for this codebase.
